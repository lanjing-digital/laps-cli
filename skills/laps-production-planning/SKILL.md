# 生产计划、到货与备货

先读 [命令手册](references/commands.md)。先读取真实订单、齐套和计划ID与版本，再说明写入范围。到货跟进、预计采购和实际入库分别解释，不能把预计到货当已齐套。

计划分析会保存分析并可能影响相关业务，不称为零写入试算。计划确认、采购确认和备货均先获得明确授权。备货可能消耗预留并生成已过账单据，先查询选项和库存；失败保留未完成状态。优先在当前事项直接办理，复杂编排沿用完整排程页面。
