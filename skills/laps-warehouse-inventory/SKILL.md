# 仓库库存与单据

先读 [命令手册](references/commands.md)。实际登录用户决定仓库可见性与操作权限，不用管理员或服务凭据替代。先查询仓库模式、库存版本与待到货，再选择原有正式操作。

草稿单据、已过账库存、预计到货和可用量要区分。直接调整需版本和幂等键，过账/作废先确认对象与影响。外部镜像仓库只允许查询和受控同步，不能通过切换模式绕过。外部同步先预览，同一输入确认后应用，正式业务服务重核约束。
