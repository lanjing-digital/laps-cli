# 生产进度与动态重排

先读 [命令手册](references/commands.md)。读取真实目标和历史报工，按事件、数量、时间与幂等键提交；不能根据模型推测补完工或更新进度。

动态重排先查询原因和候选，预览后用同一候选及预览凭证确认，不重算替换已认可方案。报工、初始化、风险关闭与配置修改都先确认。个人记忆只能补全参数，不能替代实时进度、权限与版本核验。
