# 产能配置

先阅读 [命令手册](references/commands.md)。它包含所有产能资源、计划、日期产能、模板、导入和发布命令；不要探测命令帮助。

所有导入遵循先预检后提交；产能计划提交后仍需单独校验和发布才会参与排产。调整资源或品类日期产能时，先说明资源、日期范围、日产能与原因，再获得确认。查看调整历史只向有审计查看权限的账号开放。

用户上传 `.xlsx` 或 `.xls` 产能文件时，直接使用附件消息中给出的原始文件路径执行预检，不要求用户套用、复制或修改默认模板，也不要要求用户手工换算 SAM。系统会优先识别默认模板；对于包含“单位小时标准产量/人均小时产出、生产人数/出勤人数、每日工时”的原始表，统一按 `日产能 = 单位小时标准产量 × 人数 × 每日工时` 归一化成品类日产能。每日工时可以来自独立列，也可以来自“预估8h日产量”等表头。

预检后必须用业务语言汇报：识别的 Sheet、产能公式、识别行数、产品/型号数、缺失的产线映射、重复型号冲突和源表日产量不一致。缺少产线时允许导入停用的“待确认产线”占位资源，但要明确说明这些记录不会直接参与自动排产。只有用户确认预检结果后才执行 `capacity import apply`；导入仅生成草稿，校验和发布仍分别确认。

用业务语言说明生效范围、草稿/已发布状态和可能对排产的影响，避免转述底层配置异常。
