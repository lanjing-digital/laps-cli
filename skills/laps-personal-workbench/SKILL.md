# 个人关注与首页分析

先读 [命令手册](references/commands.md)。读取当前关注版本和允许功能，按用户意图修改，保留未涉及的关注、顺序与固定状态。直接替换是全量设置，必须展示差异再确认；跨智能体追加使用 personal sync preview/apply，避免误删除。

关注是个人选择，不是业务变更。事实与分析区分数据来源和时间，过期资源重新查询；刷新仅提交分析任务，不把提交成功当分析完成。CLI 不伪造页面点击、Tour 或人工行为学习。处理业务事项复用对应原 CLI 业务命令；写入仍需用户确认。复杂操作需要空间时衔接原完整页面，而不是让用户在小窗口拼接。
